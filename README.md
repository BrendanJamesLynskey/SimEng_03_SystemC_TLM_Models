# Simulation Engineering Toolkit 03 — C++ Performance Models with SystemC TLM-2.0

An FHE accelerator tile in C++17 and SystemC, driven by the SimPy simulator's own traces: modern C++ for models, the SystemC kernel and delta cycles, TLM-2.0 sockets and payloads, approximately- and loosely-timed coding, temporal decoupling and the quantum, why tie-breaks are part of the model, op-by-op agreement with SimPy, GoogleTest and sanitizers.

Topics: SystemC, TLM-2.0, C++17, AT and LT, Temporal decoupling, GoogleTest, ASan/UBSan.
